# skills/memory/workflows/

The four workflows `SKILL.md` dispatches. All four must survive every install
path; a missing `check-against-memory.md` leaves a filing cabinet.

- `wrap-session.md` - "I'm done" writes the dated session log; carries the
  vague-next-step, missing-reason, and private-information refusals and the
  one-message day-dump path.
- `recall.md` - "what did we decide about X?" answers with the date, the
  reasoning, and the actual entry.
- `check-against-memory.md` - the contradiction check; matches a new idea to a
  standing decision by subject and asks supersede-or-exception.
- `memory-brief.md` - "what changed this month?" rolls the period into one dated
  forwardable page, with the reversals section and the optional branded HTML.
